# AI Agents Thought Process Log

Persistent knowledge base for Claude Code sessions working on Shaggoth AI and related projects.

## Purpose
Track decisions, findings, and context across sessions so future AI agents can understand:
- What was tried and why
- What worked vs what didn't
- Current state and next steps
- Architectural decisions and rationale

## Structure

- **sessions/** - Daily session logs with chronological work
- **decisions/** - Key architectural and technical decisions
- **findings/** - Technical discoveries and learnings
- **context/** - Project context and current state

- **Shaggoth AI Training** - DeepSeek-R1/Qwen2.5 fine-tuning on R510
- **P3 Lending Platform** - DeFi protocol on R510/R410
- **Command Center** - Monitoring dashboard
- **Infrastructure** - R410/R510 homelab setup
